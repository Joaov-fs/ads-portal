\# ADS Platform



&#x20;Plataforma brasileira de conteúdo e ferramentas inteligentes para decisões financeiras, trabalhistas, tributárias e econômicas.



\---



\# VISÃO DO PRODUTO



Este projeto NÃO é um blog.



Este projeto NÃO é apenas um portal de notícias.



Este projeto NÃO é apenas um conjunto de calculadoras.



Este projeto é uma plataforma.



Nosso objetivo é transformar assuntos complexos em experiências simples.



O usuário deve conseguir entender uma mudança, calcular como ela impacta sua vida e encontrar conteúdos relacionados sem precisar sair do site.



O foco principal é gerar valor para o usuário.



A monetização será consequência da experiência.

\# PUBLICIDADE



A monetização será feita inicialmente com Google AdSense.



Cada página deverá possuir aproximadamente cinco posições preparadas para anúncios.



Não utilizar pop-ups invasivos.



Não utilizar publicidade que prejudique a experiência.



Estrutura recomendada



Banner após o header



Banner antes do conteúdo principal



Banner após o resultado da calculadora



Banner antes do conteúdo relacionado



Banner próximo ao rodapé



Todos deverão utilizar um componente reutilizável chamado AdSlot.



No MVP esses espaços poderão ser placeholders.
